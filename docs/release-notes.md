# ClipZero 1.0.0（待发布）

首个版本专注于防止 Windows 桌面和资源管理器误粘贴文件：复制或剪切文件后，托盘图标变黄；点击图标即可取消待粘贴状态。

## 功能

- 通过 Windows 原生剪贴板通知检测标准文件与文件夹列表，区分复制、剪切与未知类型。
- 显示完整项目数量及最多 8 个文件名预览。
- 灰色/黄色/棕色托盘状态、右键菜单和紧凑主窗口；默认仅驻留托盘，`--show` 打开窗口。
- Ctrl+Alt+Backspace 清空快捷键，冲突时提示并保留其他操作入口。
- 清空前在剪贴板锁内核对版本和有效文件数据，过期请求不清除新复制内容。
- 剪贴板占用时有限重试，STA 工作线程避免延迟渲染阻塞 UI。
- 窗口「刷新」和托盘「刷新状态」可重试读取；没有待粘贴文件时单击灰色托盘保持安静，相同提示短时间内不重复弹出。
- 主窗口支持缩小后滚动，撤销配置操作结果保留在窗口中；备份有效且当前值仍为原值时，可重试未完成的写入或安全清理备份。
- 单实例、高 DPI、普通用户权限；不联网、不保存剪贴板历史、不修改原文件。
- 在主窗口和托盘右键菜单集成可选「文件撤销设置（实验性）」，提供「尝试关闭撤销」「恢复原设置」；中文状态和操作结果、精确备份与恢复。由 C# 直接实现，无需额外脚本，不会默认修改设置。配置保存不等于隐藏或禁用菜单，实际效果未确认。

## 下载与运行

选择与处理器匹配的 `win-x64` 或 `win-arm64` 包。`self-contained` 提供包含 .NET 10 的应用 EXE，无需另装运行时；`framework-dependent` 较小，需要相同架构的 .NET Desktop Runtime 10，必须保留整个发布目录。

本工作目录中已有发布 ZIP 来自先前构建，不包含本次软件内集成功能。当前修改先由源码构建、运行并验收，不重新打包或发布 Release；上述下载说明适用于后续完成验收的版本。

解压后运行 `ClipZero.exe`，从托盘右键菜单退出。独立运行单文件启用压缩，启动需解压；首次启动会将原生运行时解包至 `%TEMP%/.net`，可能稍慢。源代码和构建命令见 [README](../README.md)，发布流程见 [发布指南](releasing.md)。

如需尝试限制 Explorer 文件撤销，在软件的「文件撤销设置（实验性）」中点击「尝试关闭撤销」。刚写入后可保存工作并注销、重新登录一次再检查，不必反复注销。灰色菜单项当前无法点击，但不代表后续始终禁用；重新登录后若新文件操作仍能撤销，就应视为方案无效，点击「恢复原设置」。当前机器的项目仍显示为灰色，彻底隐藏尚未实现。完整说明见 [实验性设置](explorer-undo.md)。

## 已知限制

- 只识别 `CF_HDROP`，不支持邮件附件和部分软件的虚拟文件格式。
- 含文件的混合格式剪贴板项目会整体清空；纯文本不清空。
- 不清理 Win+V 或第三方剪贴板历史，历史工具重新复制属于新项目。
- 清空剪贴板不会移除 Explorer 撤销菜单。实验性设置尝试影响整个 Explorer 文件操作撤销/重做，包括 Ctrl+Z / Ctrl+Y，使用未公开配置，不能保证隐藏或禁用菜单；「关闭设置已保存，效果未确认」只表示配置保存成功。
- 不设置自启动，不定时清空，不自动更新；未签名 EXE 可能出现 SmartScreen 下载提示。
